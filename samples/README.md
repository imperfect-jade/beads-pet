# Local Bead Image Samples

Real bead photos are local development material and should not be committed.
Place them under `samples/local/` or `output/samples/`.

Recommended coverage for the first sample set:

- white background, front-facing
- tabletop background
- tilted capture
- strong shadows
- multiple bead objects
- partial crop
- PNG, JPG, and WebP files

Use `samples/manifest.example.json` as a starting point for a local manifest.
